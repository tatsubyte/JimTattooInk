# JimTattooInk
Sitio web oficial de JimTattooInk - Estudio de tatuajes blackwork en Barcelona
Arrastrar el archivo: Arrastra la foto nueva (ej. 15.avif) desde tu carpeta de Windows y suéltala directamente encima de la carpeta desing (o blackwork, color, etc.) en el panel izquierdo de VS Code.

Duplicar un bloque con atajo de teclado: En disenos.html (o tattoo.html), selecciona el último bloque <article>...</article> (o <figure>...</figure>), presiona Shift + Alt + Flecha Abajo y VS Code creará una copia idéntica debajo.

Cambiar el número: Solo cambia el número 14 por 15 en el archivo (15.avif), en la etiqueta (#15) y en el enlace de WhatsApp (%2315).
